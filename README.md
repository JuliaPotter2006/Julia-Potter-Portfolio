# Portfolio
This repository contains all of the projects I have completed as a data science major at Wasington &amp; Jefferson College.
## SAMHSA Data Visualization Report
* Created in May 2026 using Tableau and Word for Information Visualization (CIS245)
* A 10-page report synthesizing SAMHSA survey data into compelling insights on the prevalence of adolescent depression in the United States and the necessity of early intervention. Includes four polished visualizations to convey complex public health data to a general audience.
* Folder contains report as a Word Document and a Tableau Packaged Workbook of visualizations
## Spotify Data Analysis Report
* Created in May 2025 using Python and Jupyter for Introduction to Data Science (CIS241)
* A report analyzing a complex dataset derived from Spotify’s song popularity ranking, complete with polished data visualizations. Culminates in using a random forest regression model, built in Python using scikit-learn, to identify song characteristics that best predict chart performance, with song energy and release year emerging as the top predictor variables.
* Folder contains HTML file of the report as a Jupyter notebook
## Anime Database Design Project
* Created in May 2025 using PostgreSQL for Database Concepts (CIS112)
* A multi-user, general purpose database that stores anime watch history, personal reviews, and extensive metadata for said anime. Includes a range of built-in functions that allow for easy data input, manipulation and analysis. 
* Folder contains SQL dump file and extensive README documentation
